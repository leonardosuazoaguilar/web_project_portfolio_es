# Portafolio

## Descripción del proyecto

Este proyecto es mi portafolio web personal como Desarrollador Full-Stack Junior. Su funcionalidad principal es servir como una tarjeta de presentación interactiva para mostrar mi perfil profesional, mis habilidades técnicas y mis proyectos destacados. El sitio está estructurado y estilizado para garantizar una navegación clara y una experiencia visual atractiva en diferentes dispositivos.

## Tecnologías y técnicas utilizadas

- HTML5 semántico
- CSS3 (Flexbox, posicionamiento absoluto/relativo)
- Flexbox: Para la distribución de espacios, alineación de elementos en la cabecera, la cuadrícula de proyectos y la sección de contacto.
- Diseño Responsivo (Media Queries): Adaptación de la interfaz para pantallas de escritorio, tablets (1024px) y dispositivos móviles (767px), asegurando que ningún elemento desborde su contenedor.
- Metodología BEM (Block, Element, Modifier): Convención de nomenclatura para las clases de CSS , manteniendo el código escalable y organizado.
- Posicionamiento Avanzado: Uso de "position: absolute" y "relative" para crear efectos visuales complejos, como los gradientes radiales de iluminación en el fondo y las capas de superposición (overlays) en las tarjetas de proyectos.
